# WeChat Native Client Agent Rules

- 使用微信官方推荐的原生小程序开发方式、UI、生命周期与 API。
- 本工程是实验 baseline，不依赖 KMP 内部实现。
- 不为了与 KMP 保持代码结构一致而人为改变微信原生工程。
- 后续两套客户端应实现相同业务能力，并接受相同验收场景。
- 保留微信原生方案真实的开发成本和工程特征，否则对照数据无效。
- 仅通过已确认的 Backend API、协议和需求事实与其他模块协作。
- 当前阶段保留已有示例，不新增正式页面或业务逻辑。
- 两套客户端共同遵守 `../docs/api/openapi.yaml`，不得各自发明字段、告警等级或阈值单位。
- 目标能力包括 ECharts 实时仪表盘、温湿度/气体趋势、远程静音、阈值滑块和历史告警；当前只记录契约，不实现页面。
- 负责微信原生端的成员/Agent 必须依照根规则使用 `multica` CLI，同步页面/组件、微信 API、接口联调、开发者工具验证和阻塞。
- 微信原生端修改遵守根 Git/PR 流程，分支使用 `feat/wx-...`、`fix/wx-...` 等完整名称；PR 应附微信开发者工具及真机验证状态。
